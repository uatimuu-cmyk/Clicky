# Clicky

<p align="center">

</p>

A lightweight autoclicker built with Python and PySide6.

## Features

- Automated mouse clicking
- Configurable clicking speed
- Graphical user interface
- Keyboard controls

## Download

Download the latest Windows executable from [Releases](https://github.com/uatimuu-cmyk/Clicky/releases).

## Run from source

Install the dependencies:

```bash
python -m pip install PySide6 pynput
```

Run Clicky:

```bash
python autoclicker.py
```

## Build

Windows builds use GitHub Actions and PyInstaller.

## Dependencies

- Python
- PySide6
- pynput
- PyInstaller
